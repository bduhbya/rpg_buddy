## Reproducible human walkthrough

Preconditions: from the repository root, use its declared Node/npm versions and installed dependencies. Python checks use the existing .venv-contracts environment. No rulebook file, library, network service or launched desktop is required.

1. Read src/domain/architecture.md and trace its file-labeled diagram. calculateWithEntries calls the shared calculation engine, which validates entries through validateEntryEffects and the operation registry before arithmetic. Follow base expression evaluation, effect application, final-number checking and insertion into the dependency cache. Confirm caller instances are not written to.
2. Run `npm run test:unit -- tests/unit/domain/calculate-with-entries.test.ts`. Inspect the authored Ork table: T45 and T49 yield TB8; T50 yields TB10. The constructed simultaneous-feature case yields SB8/TB6, while the S49/T49 round-trip case yields SB8/TB8. These are test creatures, not a legality claim or complete character profile.
3. Inspect the downstream test: SB4 becomes8, TB reads8 and becomes24, and AB reads24, producing movement24/48/72/144. Reversed field declarations must still pass. The six boundary rows verify independent modified values including zero-row movement0.5/1/2/3.
4. Run `npm run test:unit -- tests/unit/domain/validate-entry-effects.test.ts tests/unit/domain/effect-operations.test.ts`. Expect invalid targets, factors and operations to fail at the relevant pointer. The conflict tests cover duplicates within/across entries and identify the earlier effect through related locations. Confirm descriptions and duplicate labels do not become mechanics.
5. In the effect integration suite, inspect the unsafe-result and recovery tests. Multiplying 2^52 by2 must return NONFINITE_RESULT at the entry factor, related to the template expression, with no partial value. Invalid factor0 must preserve the prior SB8 result; changing to3 produces a fresh SB12, and removing the entry returns SB4.
6. Run `npm run test:unit -- tests/unit/domain/calculation-engine.test.ts tests/unit/domain/calculate-base.test.ts`. Verify shared expression/input/graph acceptance and the base-only API smoke test. The authored Ork base-only output remains TB4.
7. Run `.venv-contracts/Scripts/python data_contracts/verify_contracts.py`. Expect 10 passing integrity groups. Inspect verification/expressions.py to confirm it validates expressions without evaluating them; verification/validation.py must expose no calculation API.
